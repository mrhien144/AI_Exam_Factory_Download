Cài đặt an toàn trên Windows

AI Exam Factory được phát hành dành cho Windows 10/11 64-bit. Trong một số trường hợp, Windows SmartScreen có thể hiển thị cảnh báo với phần mềm mới tải từ Internet.

1

Tải từ trang chính thức

Chỉ tải AI Exam Factory từ trang này để bảo đảm bạn đang sử dụng đúng bộ cài do nhà phát triển phát hành.

2

Nếu Windows SmartScreen xuất hiện

Kiểm tra tên file là AI_Exam_Factory_Setup_x.x.x.exe. Nếu file được tải từ trang chính thức, chọn More info rồi chọn Run anyway để tiếp tục.

3

Cài đặt cho tài khoản hiện tại

Khi được hỏi chế độ cài đặt, khuyến nghị chọn Install for me only (recommended).

Lưu ý: Không cài đặt các bản AI Exam Factory được chia sẻ lại từ nguồn không xác định hoặc đã bị đổi tên/chỉnh sửa.

Xác minh bộ cài

Bạn có thể đối chiếu mã SHA-256 dưới đây để kiểm tra file cài đặt tải về có đúng với bản phát hành chính thức của AI Exam Factory hay không.

SHA-256 • AI Exam Factory 1.0.0
1DA59F18A49FE72BA59294932D9FD6B42F3D2C0A2E84D7ABF46393B07AA3DA0C
Cách kiểm tra trên Windows:

Mở PowerShell tại thư mục chứa file vừa tải, sau đó chạy:

Get-FileHash .\AI_Exam_Factory_Setup_1.0.0.exe -Algorithm SHA256

Nếu mã Hash hiển thị giống hoàn toàn mã ở trên, file tải về chưa bị thay đổi so với bản phát hành chính thức.
